# Employee Leave Management System API

Enterprise employee leave tracking, balance calculation, and manager approval service.

## Features
- Employee leave entitlement calculation (Annual, Sick, Casual).
- Leave request submission, cancellation, and manager approval workflows.
- Departmental leave calendar and conflict prevention.

## Tech Stack
- Java 21 LTS (backwards-compatible bytecode target)
- Spring Boot, Spring Data JPA
- MySQL 8.0
- Maven Wrapper

## Running
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
